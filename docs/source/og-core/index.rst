OG-Core user manual
===================

OG-Core helps you study how tax, spending and population changes may affect
the economy. It represents people of different ages and income groups.
OG-PHL is the version prepared for the Philippines.

In this guide, you will create a baseline, make a tax change, run both cases
and compare the results. A **baseline** is your reference policy. A
**reform** is a policy change measured against that baseline.

The example cuts the model's corporate income tax rate from 25% to 20%.
It is a learning exercise, not a policy recommendation. Results depend on
the model's assumptions.
