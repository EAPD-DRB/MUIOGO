Short glossary
==============

.. glossary::

   Baseline
      The reference policy and assumptions used for comparison.

   Calibration
      Data and assumptions that adapt OG-Core to a country.

   Case
      A saved baseline and its linked reforms in a country workspace.

   Parameter
      An input, such as a tax rate or spending share.

   Reform
      A policy change compared with a specified baseline.

   Run
      A calculation using saved inputs and a chosen analysis.

   Steady state
      The economy's long-run position under the model's assumptions.

   Transition path
      The model's calculated adjustment over time.

   Lifetime-income group
      A group defined by earning ability over a lifetime.

   GDP
      Gross domestic product: the value of production in the economy.

   Consumption
      Goods and services used by households.

   Capital stock
      Productive assets used by the economy.

   Gini
      A measure of inequality. Higher values usually mean more inequality.

   CSV
      A table file that a spreadsheet app can open.

   SVG
      An image format that stays sharp when resized.

   PNG
      An image format suitable for documents, presentations and sharing.

   Percentage point
      The difference between percentages. A rise from 5% to 6% is one percentage point.

   Population-weighted average
      An average that gives each age and income group its share of the model's population.
