.. container:: installation-options

   **Mac**

   .. code-block:: bash

      xcode-select --install

   Or, if you use Homebrew:

   .. code-block:: bash

      brew install git

   **Windows — PowerShell**

   .. code-block:: powershell

      winget install -e --id Git.Git

   **Linux — Debian / Ubuntu**

   .. code-block:: bash

      sudo apt install git

   **Linux — Fedora / RHEL**

   .. code-block:: bash

      sudo dnf install git

   You can also `download Git directly <https://git-scm.com/downloads>`_.
